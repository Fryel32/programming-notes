# Fundamental Pemrograman Python

Selamat datang di modul dasar pemrograman Python, Folder ini berisi catatan terstruktur, contoh kode, dan penjelasan lengkap yang membahas fondasi Python, mulai dari sintaks dasar hingga Pemrograman Berorientasi Objek (OOP).

## Jalur Belajar (Roadmap)

Silakan pilih dan klik topik di bawah ini untuk membuka file dokumentasi materi:

1. **[Dasar Python (Basic)](Basic.md)**
   - Pengenalan sintaks, variabel, dan tipe data dasar.
   - Operasi Input/Output dan operator aritmatika.

2. **[Kontrol Alur (Control Flow)](control-flow.md)**
   - Percabangan/kondisional (`if`, `elif`, `else`).
   - Perulangan (`for`, `while`) serta kontrol perulangan (`break`, `continue`, `pass`).

3. **[Struktur Data (Data Structures)](data-structures.md)**
   - Koleksi bawaan Python: List, Tuple, Set, dan Dictionary.
   - Metode manipulasi data, indexing, slicing, dan list comprehension.

4. **[Fungsi (Functions)](functions.md)**
   - Cara membuat dan memanggil fungsi (`def`).
   - Parameter, argumen (`*args`, `**kwargs`), return value, dan fungsi `lambda`.

5. **[Modul & Paket (Modules)](modules.md)**
   - Cara impor library bawaan dan file lokal (`import`, `from`).
   - Manajemen paket menggunakan `pip` dan struktur proyek.

6. **[Penanganan Error (Exceptions)](exceptions.md)**
   - Mengatasi error saat program berjalan dengan `try`, `except`, `else`, dan `finally`.
   - Cara memicu error kustom menggunakan `raise`.

7. **[Pemrograman Berorientasi Objek (OOP)](oop.md)**
   - Konsep Class, Object, dan constructor `__init__`.
   - 4 Pilar OOP: Inheritance (Pewarisan), Polymorphism, Encapsulation, dan Abstraction.
