# Programming Fundamentals

Selamat datang di repositori fundamental pemrograman. Repositori ini dirancang untuk membantu menguasai konsep dasar pemrograman di berbagai bahasa dan algoritma.

## Daftar Materi

*   **Python**: [Buka Materi Python](./Python/) - Dari variabel hingga Object-Oriented Programming (OOP).
*   **JavaScript**: [Buka Materi JavaScript](./javascript/) - Menguasai DOM, ES6, hingga Asynchronous.
*   **Go (Golang)**: [Buka Materi Go](./go/) - Belajar *statically typed*, *goroutines*, *pointers*, dan *interfaces*.
*   **PHP**: [Buka Materi PHP](./php/) - Memahami *superglobals*, *arrays*, penanganan *form*, hingga OOP PHP.
*   **C++**: [Buka Materi C++](./cpp/) - Belajar memori, *pointers*, dan Standard Template Library (STL).
*   **🗄️ SQL**: [Buka Materi SQL](./sql/) - Manajemen database, JOIN, dan normalisasi data.
*   **📐 Algorithms**: [Buka Materi Algoritma](./algorithms/) - Memahami kompleksitas kode (Big O), sorting, dan rekursi.
